# PixelFlow

An asynchronous image compression service that allows users to upload images, process them in the background through a simple web interface.

The application uses a queue-based architecture to separate image processing from the request lifecycle, ensuring a responsive user experience while handling resource-intensive compression tasks efficiently.

---

## Features

- User authentication
- Image upload
- Asynchronous image compression
- Background job processing
- Compression status tracking
